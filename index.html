Faceless Desk

A private, single-user publishing tool for the YouTube channels owned by one creator.

What it does

Faceless Desk is a command-line tool that runs only on the channel owner's computer. It is not offered to the public and has no other users. The owner authorizes it once per channel with Google OAuth 2.0, and then uses it to:

  • Upload the owner's own finished videos to the owner's own channels, always as private and scheduled for publication, and only when the owner runs the upload command for that video.
  • Set the title, description, tags, language and thumbnail of those videos.
  • Read the analytics of the owner's own channels (views, retention, traffic sources, impressions and click-through rate) to decide what to improve.

The channels it currently manages are Mando Federal MX and México No Cede.

Data

Faceless Desk uses YouTube API Services. It never accesses any channel other than the owner's, stores its OAuth tokens only on the owner's computer, and shares no data with anyone. Details are in the Privacy Policy.
