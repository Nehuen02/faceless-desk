Faceless Desk — Privacy Policy

Last updated: October 22, 2026

Who uses this tool

Faceless Desk is a private command-line tool used by a single person, the owner of the YouTube channels it manages (currently Mando Federal MX and México No Cede), to manage only the owner's own channels. It is not offered to the public and has no other users.

YouTube API Services

Faceless Desk uses YouTube API Services (the YouTube Data API v3, the YouTube Analytics API and the YouTube Reporting API). By using Faceless Desk you agree to be bound by the YouTube Terms of Service. Google's handling of data is described in the Google Privacy Policy.

What data is accessed

  • OAuth tokens issued by Google when the owner authorizes the tool for each of the owner's channels.
  • Data of the owner's own channels: the list of uploaded videos, their titles, descriptions, tags, thumbnails, privacy and scheduling settings, and aggregated analytics (views, watch time, retention, traffic sources, playback locations, impressions and click-through rate).
  • The owner's own video files and thumbnails, read from the owner's computer only to upload them to the owner's channels.

The tool does not access data of any other YouTube user or channel, and does not collect personal information of viewers.

How the data is used

Only to upload and schedule the owner's videos, edit their metadata, and show the owner how the videos perform.

Storage

OAuth tokens are stored only on the owner's own computer. Downloaded analytics are stored on the owner's computer and in the owner's private backup repository, which only the owner can access. Nothing is stored on any server operated by the tool, because there is none. At least every 30 days the tool re-confirms with Google that it is still authorized to access each channel; if access has been revoked, the stored data obtained from that channel is deleted. Data other than analytics is refreshed or deleted within 30 days, as the YouTube API Services policies require.

Third-party content and advertising

The tool shows no third-party content and no advertising, and neither does this website.

Sharing

No data is sold, shared with, or disclosed to any third party.

Cookies

The tool runs on the command line and does not use cookies or any tracking technology. This website does not use cookies either.

Revoking access

Access can be revoked at any time from the Google security settings page: https://security.google.com/settings/security/permissions. Deleting the token files from the owner's computer also removes the tool's stored access.
